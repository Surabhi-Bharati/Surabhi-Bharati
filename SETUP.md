# CODEX ASTRALIS — setup

1. Create or open the special profile repository named `Surabhi-Bharati`.
2. Keep `README.md` at the repository root.
3. Upload the `assets/` directory without changing its name.
4. Optionally add `.github/workflows/snake.yml` to enable the contribution snake.
5. Commit to the default branch. GitHub Actions may need to be enabled in repository settings.

The header SVG uses SVG SMIL animation. GitHub's SVG sanitization/rendering can vary;
if motion is not shown in a particular client, the artwork still has a complete static
fallback. The typing line uses an external SVG service and requires network access.

No GIFs, JavaScript, embedded stylesheets, or external CSS are used in the README.
